# 有料資料カード作成スキル

作業ディレクトリは `wordpress-paid-materials/`。

- `cards/paid-NNN-<英語スラッグ>.html` … WordPress「カスタムHTML」ブロックにそのまま貼るカード本体
- `template/card-template.html` … 新規カードの雛形
- `build-preview.mjs` … `preview.html`（プレビュー＋HTMLコピー画面）を生成
- `preview.html` … 自動生成物。直接編集しない

## 入力（ユーザーが貼る原稿）
- 📌 タイトル（【有料レポート】＋本題＋（括弧の補足：論文番号・発表元・日付など））
- 💡 キャッチコピー（「」の一文＋補足一文）
- 🔍 お悩み（2〜6項目）
- 📄 得られる価値（通常4項目：見出し＋説明）
- 💰 価格・形式（1〜3項目）
- 🚀 決済方法（MemberPress / Stripe など）

## 手順
1. 新規カードは `cards/paid-NNN-<英語スラッグ>.html` を作成（番号は既存ファイルの最大値+1、3桁ゼロ埋め）。
2. 雛形 `template/card-template.html` の `{{...}}` をすべて置換し、繰り返しブロック（`<!-- REPEAT -->` 〜 `<!-- /REPEAT -->`）は項目数ぶん複製、`REPEAT` / `OPTIONAL` のマーカーコメントは削除。
3. 購入URL `{{BUY_URL}}` は決済方法に応じたプレースホルダ（`MEMBERPRESS_URL` / `STRIPE_URL` 等）にする（2か所）。
4. `node wordpress-paid-materials/build-preview.mjs` を実行して `preview.html` を再生成する。
5. ユーザーに確認してもらう：`wordpress-paid-materials/preview.html` をユーザーに送る（SendUserFile, `display: "render"`）。ローカルではブラウザで開けばよい。プレビュー画面で番号タブを選び「#NNN のHTMLをコピー」で WordPress に貼れる。
6. 返信では、作成・修正したカード番号、購入URLの差し替え箇所（2か所）、原稿から直した誤字があればそれを伝える。

修正指示（「#003 のキャッチを〜に」など）の場合は該当カードだけを編集し、手順4〜6を行う。指示が無い限り既存カードの様式（構造・色・余白）は変えない。

## 変換ルール
- 左パネル：バッジ「有料レポート」＋論文番号バッジ（無ければ省略）、本題（【有料レポート】と括弧部分を除く）、括弧内の補足を2行程度に分割。
- 右パネル：キャッチコピー「」部分を見出し、補足文を本文（末尾は「。」）。価格横の小文字は「（税込）／ 形式の要約」。
- 価値の見出しから【視覚的理解】【即実践】等の隅付き括弧ラベルは外し、短く整える。「【TEL×Samsung両視点】友安昌幸による実務翻訳」は「TEL × Samsung 両視点の実務翻訳」とし、人名は説明文側に入れる。
- 原稿の文言は改変しない（明らかな誤字のみ修正し、ユーザーに報告）。絵文字は使わない。
- スタイルはすべてインライン（WordPressテーマCSSの影響回避）。`<style>` や `<script>` は使わない。色・余白・構造は雛形から変えない。
