# 有料資料カード作成スキル

原稿から WordPress「カスタムHTML」ブロックにそのまま貼れるカードを作り、プレビュー画面（タブ切替・プレビュー・HTML表示・ワンクリックコピー）を更新して、ユーザーが見た目を確認しながら指示を重ねられるようにする。

## 作業ディレクトリ

既定はプロジェクト直下の `paid-materials/`（ユーザーが別の場所を指定したらそれに従う）。

```
paid-materials/
├── wordpress/paid-NNN-<英語スラッグ>.html   # カード本体（1枚1ファイル）
└── preview.html                              # 生成物：確認・コピー用プレビュー
```

このスキルのディレクトリ（以下 `<skill>`）には `template.html`（雛形）と `scripts/build-preview.mjs`（プレビュー生成）がある。

## 入力（ユーザーが貼る原稿）
- 📌 タイトル（【有料レポート】＋本題＋（括弧の補足：論文番号・発表元・日付など））
- 💡 キャッチコピー（「」の一文＋補足一文）
- 🔍 お悩み（2〜6項目）
- 📄 得られる価値（通常4項目：見出し＋説明）
- 💰 価格・形式（1〜3項目）
- 🚀 決済方法（MemberPress / Stripe など）

## 手順

### 新規カード
1. `paid-materials/wordpress/` の既存ファイルの最大番号 +1 を3桁ゼロ埋めで `NNN` とし、`paid-NNN-<英語スラッグ>.html` を作成する。
2. 雛形 `<skill>/template.html` の `{{...}}` をすべて置換する。繰り返しブロック（`<!-- REPEAT -->` 〜 `<!-- /REPEAT -->`）は項目数ぶん複製し、`REPEAT` / `OPTIONAL` のマーカーコメントは削除する（先頭・末尾の「有料資料カード #NNN」コメントと「差し替え箇所」コメントは残す）。
3. 購入URL `{{BUY_URL}}` は決済方法に応じたプレースホルダ（`MEMBERPRESS_URL` / `STRIPE_URL` 等）にする。
4. プレビューを再生成する：
   ```bash
   node <skill>/scripts/build-preview.mjs paid-materials
   ```
5. ユーザーにプレビューを見せる（下記「プレビューの見せ方」）。差し替えが必要な購入URL（2か所）と、誤字修正をした場合はその箇所を伝える。

### 修正指示（「見出しを短く」「お悩みを1つ追加」など）
対象カードのファイルを直接編集し、手順4・5を繰り返す。番号は変えない。

### プレビューの見せ方
- ローカル環境：`paid-materials/preview.html` をブラウザで開くよう案内する（`file://` で直接開いて動作する）。
- 画面にファイルを表示できる環境（クラウドセッション等）：`preview.html` をユーザーに送って表示する。
- プレビュー画面では、上部の `#NNN` タブでカードを切替、「HTMLを表示」でソースを確認、「#NNN のHTMLをコピー」でクリップボードにコピーできる。コピーできない環境では自動でソース欄が開くので、全選択してコピーしてもらう。

## 変換ルール
- 左パネル：バッジ「有料レポート」＋論文番号バッジ（無ければ省略）、本題（【有料レポート】と括弧部分を除く）、括弧内の補足を2行程度に分割。
- 右パネル：キャッチコピー「」部分を見出し、補足文を本文（末尾は「。」）。価格横の小文字は「（税込）／ 形式の要約」。
- 価値の見出しから【視覚的理解】【即実践】等の隅付き括弧ラベルは外し、短く整える。「【TEL×Samsung両視点】友安昌幸による実務翻訳」は「TEL × Samsung 両視点の実務翻訳」とし、人名は説明文側に入れる。
- 「本資料で得られる{{VALUE_COUNT}}つの価値」の数は価値の項目数に合わせる。
- 原稿の文言は改変しない（明らかな誤字のみ修正し、ユーザーに報告）。絵文字は使わない。
- スタイルはすべてインライン（テーマCSSの影響回避）。色・余白・構造は雛形から変えない。
- 既存カード（`wordpress/paid-*.html`）の様式は、ユーザーの指示がない限り変更しない。
