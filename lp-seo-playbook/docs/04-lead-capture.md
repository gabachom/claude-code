# フェーズ4: リード獲得装置(来た人を「問い合わせ」に変える)

使うスキル: **lead-capture**

検索で人を集めても、動いてもらう仕掛けがなければ素通り。**測る装置(診断)**と**読む装置(ホワイトペーパー)**でリードを取る。

## 手順

1. **8問診断を作る**: 5軸レーダー・簡易結果は無料表示・詳細レポートはメールと交換(リードゲート)。**LP最上部の一番目立つCTAを「1分で無料診断」に変える** — 資料請求より心理的ハードルが低い入口を最前面に置くと動く人が増える
2. **ホワイトペーパーを作る**: 「◯◯導入の完全ガイド — 導入ステップ×注意点」型。一次ソース(公式ドキュメント・OWASP等)だけを根拠に、煽らない読み物。原稿1本からPDF・スライドへ自動変換、表紙はAI生成
3. **解説動画を作る**: ホワイトペーパーの内容をAIで動画化し、資料と併置
4. **自動返信メールを組む**: 資料請求→PDF+解説動画+無料相談リンクが自動で届く

## 実績の目安(元記事)

- 診断→問い合わせの動線で **累計100件超**(最初の3週間で約70件)
- 流入の約55%が検索(広告費ゼロ)
