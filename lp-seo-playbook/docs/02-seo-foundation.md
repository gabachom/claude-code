# フェーズ2: SEOの土台(公開後、数日かけて作り込む)

使うスキル: **seo-foundation**

「2時間でLPはできた。でも検索しても1ミリも出てこない」— ページは作っただけでは存在しないのと同じ。価値があるのはページを「検索で見つかる」「放っておいても記事が増えて強くなる」状態にするこのフェーズ以降。

## 押さえるのは3つだけ

### 土台① 速い・素のHTML
- 画像を圧縮(元記事: トップ画像 498KB→46KB)
- X埋め込み・動画は遅延読み込み(初回表示 約13MB削減の実例)
- Claude Code への依頼例: 「画像を全部WebP・100KB以下に圧縮して」「X埋め込みをクリック時読み込みにして」

### 土台② 誰が書いたかを機械に伝える(構造化データ)
- 「どの会社が運営し、誰が書いた記事か」をGoogleが読めるタグ(JSON-LD)で添える = 検索エンジン向けの"名刺データ"
- 著者ページを作り、X・会社サイトと相互に紐づける = 信頼(E-E-A-T)
- Claude Code への依頼例: 「構造化データを入れて」「著者ページを作って」「robots.txtを整えて」— **頼むだけ。全部Claude Codeがやる**

### 土台③ 記事を出し続け、内部リンクでつなぐ
- 薄いページ1枚では上がらない。「完全ガイド」をハブに置き、関連記事をリンクで束ねる
- 記事の量産はフェーズ3(ブログ自動化)で仕組み化

## 仕上げ

- Google Search Console にプロパティ登録・sitemap送信(フェーズ5のデータ運用の前提)
- リッチリザルトテストで Organization / Person / FAQPage の検出を確認
