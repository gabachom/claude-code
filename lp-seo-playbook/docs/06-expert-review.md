# 専門家評価: この手法はどこまで信じてよいか(交絡分析)

元記事の実績は本物でも、**手法の効果と著者の知名度の効果が分離されていない**。無名の事業者が再現する前に、何がそのまま効き、何が割り引かれるかを仕分ける。

## 1. 著名人交絡(fame confound)の分解

| 交絡要因 | 内容 | 無名事業者への含意 |
|---|---|---|
| エンティティ権威 | 著者はXフォロワー19万・YouTube・法人を持ち、Googleに「実在が裏付けられたエンティティ」として既知。構造化データ+著者ページが効いたのは**紐づけ先に権威が既にあったから** | 構造化データは権威を作らず「指し示す」だけ。同じマークアップをしても同じ効果は出ない。権威は外部言及・被リンクで別途構築が必要(→ 07章) |
| ドメイン | LPは既存ドメインのサブドメイン(claudecode.digirise.ai)。ゼロドメインではない | 新規ドメインは同条件でもインデックス・評価に時間がかかる |
| キーワード難易度 | 「Claude Code 法人導入」は競合ほぼ不在の新興ニッチクエリ。数週間で1位はキーワード選定でほぼ説明可能 | 教訓自体は正しい(購買直結×低競合の複合語を選べ)。ただし「2時間のLPが1位」は難易度の低さの寄与が大きい |
| 指名検索の混入 | 「流入の55%が検索」には「(著者名)」「(社名)」等の指名検索=知名度がX/YouTubeで作った需要の回収分が含まれ得る | ブランド/非ブランドを分離しない限りKPIに使えない(→ 07章の計測設計) |
| 単一事例・自己申告 | 対照群なし・社内集計。受注3,200万円は商材(高単価AI支援)と営業力の寄与を含む | 手法の期待値としてではなく「上限事例」として読む |

## 2. 手法の仕分け: そのまま効く / 割り引く / 置き換える

**知名度と無関係に効く(そのまま採用)**
- 軽量な素のHTML・画像圧縮・表示速度(土台①)
- ハブ&スポークの内部リンク設計(土台③の設計原則)
- Search Console実データでの改善ループ・順位監視自動化(seo-growth)
- 診断CTA・フォーム3項目・リード運用自動化 — これはSEOではなく**CRO/オペレーション**であり、交絡の影響をほぼ受けない。本手法の中で最も再現性が高い部分

**割り引いて採用(効果は知名度依存)**
- 構造化データ・著者ページ(E-E-A-T) — やるべきだが、それ単体で順位は動かない。外部の裏付け(言及・被リンク・レビュー)とセットで初めて機能する
- 「数週間で1位」タイムライン — 低競合クエリ+既存ドメイン前提の数字

**置き換える(2026年の環境ではリスクまたは時代遅れ)**
- **毎日3本のAI記事量産** → 情報利得ゲート付きの週2〜3本へ(§3)
- **「検索1位」偏重のKPI** → AI引用+非ブランド検索+リードの3層KPIへ(§4)

## 3. 量産リスク: scaled content abuse

- Googleのスパムポリシーは「AI生成だから」ではなく「**価値のない量産**」を罰する。2026年3月コア更新では編集監督のないAI大量ページのサイトが50〜80%のトラフィック減([事例分析](https://www.digitalapplied.com/blog/scaled-content-abuse-google-march-update-ai-pages-decimated)、[日本語解説](https://aidaim.co.jp/ai-generated-articles-result-in-penalties/))
- 元記事の実データ自身が量産の限界効用を示している: **59記事・28日で1,269PV = 1記事あたり月約21PV**。集客の主役は記事群ではなくLP+知名度
- 安全ゲート(品質チェック)の思想は正しい。ただしゲートの基準に「事実性・法務」だけでなく**情報利得**(検索上位10件にない一次情報)を入れない限り、「正しいが誰でも書ける記事」が量産され、サイト全体の品質評価を薄める

## 4. AIO欠落: 「検索1位」の価値自体が目減りしている

- AI Overviewsは月間25億ユーザーに到達。**AI Overviews表示時は1位のCTRが34.5%以上低下**、検索クリック全体は前年比30%減・表示回数は49%増([2026年動向](https://www.seo-kreativ.de/en/blog/google-io-2026-seo-meaning/))
- つまり「1位を獲ったのにクリックが来ない」が常態化する。勝ち筋は「1位を獲る」から「**AIの回答に引用される**」(GEO/LLMO)へ拡張が必要([用語整理](https://guptadeepak.com/geo-compass/guides/seo-aeo-geo-aio-llmo-disambiguation/)、[実務ガイド](https://www.outerboxdesign.com/articles/ai/llmo-and-geo-what-we-know-optimizing-for-llms-and-ai/))
- 対応は **aio-optimization スキル**(AIクローラー許可・llms.txt・引用されやすい整形・AI引用モニタリング)

## 結論

元記事の価値は「LP+SEO+自動化を1人で一気通貫で組んだ実装力」と「CRO/オペレーションの作り込み」にあり、そこは模倣する価値が高い。一方「この施策でこの順位・この売上になった」という因果の主張は検証不能であり、無名事業者は**同じ施策を打っても同じ結果を期待してはいけない**。だから v2 では、施策そのものより先に**効果を自分のデータで判定できる計測ループ**(→ [07-measurement-loop.md](07-measurement-loop.md))を組み込む。
