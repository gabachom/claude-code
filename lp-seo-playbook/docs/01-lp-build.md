# フェーズ1: LP作成(目標: 骨格まで2時間)

使うスキル: **pro-lp-builder**

元記事の実績: 13:35着手 → 14:14事例追加 → 15:24骨格完成(約2時間・初日21コミット)。
「キレイなページを作ること」ではなく、**放っておいても検索から人が来て問い合わせが生まれ続ける"仕組み"を1枚に詰め込むこと**がゴール。

## 手順

1. **キーワードを1つ決める**(最重要の意思決定)
   - 「購買につながる」検索語を選ぶ(例: 元記事は「Claude Code 法人導入」)
   - ビッグワード(例:「Claude Code」)ではなく、**買う人が検索する複合語**
   - 実際にGoogleで検索し、現在の上位が企業サイトか記事かを確認(勝ち筋の確認)

2. **Claude Code に最初の指示を出す**。元記事の実際の指示:
   > 「Claude Code法人導入支援のLPをAstro(静的サイト)で作って。ヒーロー/サービス(5本柱)/活用事例/カリキュラム/導入事例/FAQ/問い合わせの構成で。クリーム+オレンジ基調で」

   本スキル環境では: 「`pro-lp-builder` スキルで◯◯のLPを作って」と依頼 → content-map.md のヒアリングに答える

3. **修正は日本語で数秒ずつ回す**。一度に全部ではなく、セクション単位で「ここをこう」と繰り返す

4. **活用事例を厚くする**(元記事は画面イメージ付き32本)。事例の数がそのまま説得力になる

5. **ビルド&デプロイ**(references/deploy-guide.md)。この時点で公開してよい — 検索の作り込みはフェーズ2で数日かけて足す
