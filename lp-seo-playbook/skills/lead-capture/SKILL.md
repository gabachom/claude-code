# lead-capture — 来た人を「問い合わせ」に変える装置

検索で人を集めても、動いてもらう仕掛けがなければ素通りする。**測る装置(診断)**と**読む装置(ホワイトペーパー)**の2つでリードを取り、その後を全自動で回す。

自動化するのは「リード獲得〜面談予約」まで。**商談そのもの(面談・提案・クロージング)は人がやる**。AIに任せるのは"入口"まで、という線引きが少人数でも商談数を積める理由。

## When to invoke(発動条件)

- 「診断コンテンツを作って」「リードゲートを作って」
- 「ホワイトペーパーを作って」「お役立ち資料を作って」
- 「問い合わせフォーム/自動返信/日程調整を作って」

## 装置① 診断(測る装置)

「8問で◯◯度が5軸レーダーで分かる」診断をLPに内蔵する。

1. **設問設計**: 8問・選択式。5つの評価軸(例: 活用度/体制/セキュリティ/人材/成果)に2問弱ずつ対応させる
2. **リードゲート方式**: 簡易結果(レベル判定+レーダーチャート)は無料でその場に表示 → **詳しいレポート(PDF)はメールアドレスと交換**
3. **LP最上部のCTAを診断にする**: 「1分で無料診断」は資料請求より心理的ハードルが低く、動く人が増える
4. **結果レポート**: 回答から Lv.1〜5 判定+軸別の推奨アクション+「おすすめの支援メニュー」を自動生成 → 自動返信メールに添付
5. 実装: 静的LPなら Google Forms + GAS、または API Route(Vercel Functions)+メール送信サービス(Resend等)

## 装置② ホワイトペーパー+解説動画(読む装置)

1. **原稿**: 「◯◯導入の完全ガイド — 導入ステップ×注意点」型。**公式ドキュメント・業界標準(OWASP等)など一次ソースだけを根拠**に、煽らず「正しく設計して使う」を語る読み物にする
2. **1原稿から多形態へ自動変換**: Markdown原稿1本 → PDF(表紙はAI生成)+スライド。解説動画もAIで制作(スライド+音声合成、またはアバター動画)
3. **配布導線**: 資料請求 → 自動返信メールに PDF+解説動画リンク+無料相談リンクを同封

## 装置③ 問い合わせ後の自動化

```
①診断・フォーム送信 → ②自動返信メール(資料PDF+予約リンク) → ③お客様が日時を選ぶ
→ ④Zoom URL自動発行・確定メール → ⑤担当へSlack通知(@メンション)
```

人が手を動かすのは面談当日だけ、を目指す。作り込みポイント:

- **担当の出し分け**: フォームの選択内容や診断結果から問い合わせ種別(例: 研修/コンサル/開発)を判定し、予約ページと通知先Slackチャンネルを自動で振り分け
- **通知の二重化**: Slack通知が万一落ちた場合に備え、確定メールを自動解析する予備ルートを用意(なりすまし防止の署名検証付き)。**1本の経路を信用しないのが自動化のコツ**
- **スパム対策**: bot対策(reCAPTCHA等)+連投制限+ハニーポット項目でリード一覧を汚さない
- **フォーム必須項目は3個まで**(名前/メール/相談内容)。7→3に減らすと完了率が上がる
- **リード管理**: 「問い合わせ→対応中→商談済み→案件化」のファネルで一覧管理(スプレッドシート+ダッシュボードで十分)。新着リードが一覧の最下部に埋もれない表示にする
- キャンセルも通知する。狙いは「取りこぼしゼロ・即対応」

## 法務チェック(必須)

- 特商法表記・プライバシーポリシーは専門家に確認
- 個人情報取得時は取得目的の明示・同意・配信停止導線を必ず設置
