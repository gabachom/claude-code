# safety-gate.md — 公開前チェックリスト(安全ゲート)

執筆AIとは**別セッション**でこの基準のみを渡して合否判定させる。1項目でもNGなら不合格。
不合格記事は公開せず、理由を日次レポートに記載する。

## 1. 事実性

- [ ] 数値・固有名詞・日付に出典があるか(自社実績は社内データ、外部情報は一次ソースURL)
- [ ] 製品仕様・料金など変わりやすい情報に「◯年◯月時点」の断りがあるか
- [ ] 引用・参照リンクが実在しリンク切れでないか(HTTPステータス確認)
- [ ] AIの幻覚チェック: 記事内の主張で検証不能なものがないか

## 2. 誇大表現・法務

- [ ] 「必ず」「絶対」「誰でも稼げる」等の断定・煽り表現がない
- [ ] 効果・成果の表現に根拠と条件が併記されている(景表法: 優良誤認・有利誤認の観点)
- [ ] 他社・競合の誹謗や事実に基づかない比較がない
- [ ] 薬機法・金商法など業界特有の規制に触れる表現がない(該当業界の場合)

## 3. 品質

- [ ] 狙いクエリに対して検索意図を満たしているか(タイトルと本文の一致)
- [ ] 既存記事との重複(カニバリ)がないか。類似記事があればリライト対象に回す
- [ ] 見出し構造が論理的か(h2→h3、飛び級なし)

## 3.5 情報利得(scaled content abuse 対策の核)

- [ ] **検索上位10件に存在しない一次情報**(自社データ・検証結果・実測値・独自スクリーンショット)が最低1つあるか — なければ不合格。「正しいが誰でも書ける記事」はサイト全体の品質評価を薄める
- [ ] 数値・主張が「出典・時点・条件」付きの自立した一文で書かれているか(AI引用可能な形)
- [ ] 冒頭段落に結論の定義文があるか

## 4. サイト整合性

- [ ] frontmatter完備(title / description / pubDate / author / tags)
- [ ] 内部リンク3本以上(うち1本はハブ記事へ)、CTA挿入済み
- [ ] サムネがPNGで存在し、OGPに設定されているか
- [ ] author が著者ページ(/author/)に紐づいているか

## 判定出力フォーマット

```json
{
  "verdict": "pass" | "fail",
  "failures": [{ "item": "1-3", "reason": "参照URLが404" }],
  "warnings": ["「劇的に」はやや煽り気味。言い換え推奨"]
}
```
